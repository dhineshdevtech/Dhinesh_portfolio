# AI Video Ads Storage

Place your video files (`.mp4`, `.webm`, `.mov`) directly into this folder.

### Recommended Naming & Formats:
- **Formats:** `.mp4` (H.264 / AAC) works universally across all web browsers and mobile devices.
- **Aspect Ratios:**
  - `9:16` (Vertical: 1080x1920) for Instagram Reels, TikTok, and YouTube Shorts ads.
  - `16:9` (Horizontal: 1920x1080) for Landscape commercials and web hero showcases.
- **Suggested Filenames:**
  - `ai-ad-1.mp4`
  - `ai-ad-2.mp4`
  - `ai-ad-3.mp4`
  - (Optional: thumbnail posters like `ai-ad-1-thumb.jpg`)

Once placed here, they can be served directly at `/videos/filename.mp4`.
